## Bill of Materials

- JLC enclosure (or another suitable box-shaped object as the base)
- KL-B101 two-pin, two-position switch (C4 switch)
- 400-point breadboard
- ESP32C3 core board
- SSD1306-driven OLED module (0.96-inch size shown in the image)
- Active buzzer
- 18650 battery pack (Type-C output)
- Electrical tape
- Velcro / double-sided tape
- Hot glue (as needed)
- Several DuPont wires

## Development Environment Requirements

- ESP-IDF v6.0.1+
- CMake 3.22+
- Python3 + pip3
